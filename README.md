# MaterialePdRugby V0.4

Inventario web statico della squadra di wheelchair rugby.

## Contenuti
- Schede giocatori aggiornate
- Gestione attrezzature, ruote, borse e inventario
- Protezione con schermata di login temporanea (SHA-256) e pulsante di Logout 🔒
- Scorciatoia rapida `CTRL + K` per la barra di ricerca

## Accesso predefinito
Password temporanea: `pdrugby2026`

## Immagini
I percorsi sono impostati in `data.js`. Caricare i file nella cartella `images/` organizzati per sottocartelle (`giocatori/`, `carrozzine/`, `borse/`, `ruote/`, `logo/`).
